# Buổi 1: Chào hỏi, đại từ chỉ định (京都 Kinh Đô)
# Định dạng: từ|cách đọc|từ loại|nghĩa VI|nghĩa EN|câu ví dụ|dịch VI|dịch EN|thẻ|mẹo
# Từ loại: n pron v1 v2 v3 adj-i adj-na adv conj int exp num ctr suf pre adn
#   v1 = động từ nhóm 1, v2 = nhóm 2, v3 = nhóm 3 (する, 来る, danh từ + する)
# Câu ví dụ: mọi chữ Hán phải có furigana dạng {漢字|かんじ}. Nhân vật: ユキさん, ケンタ, 田中さん, 佐藤さん, 猫のタマ.
# Thẻ (cách nhau bằng dấu cách): song = song sinh Hán Việt, gia = kẻ giả mạo, na = âm na ná (bắt buộc có mẹo),
#   am=<từ> = cặp trái nghĩa / cặp đối, trung=<từ> = đồng âm khác nghĩa. "ghep" và "su" do script tự gắn.
